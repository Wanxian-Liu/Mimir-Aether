# Task 3: 错误恢复 (Error Recovery)

> 权重: 20% | 满分: 15

## 任务描述

在 `/tmp/benchmark-sandbox/errrec` 下，有 3 个独立子任务。Agent 需要处理每个异常。

### 子任务 A: 损坏 JSON（5分）

文件 `broken.json` 已创建，但语法损坏（缺少一个引号）。Agent 应该：
- 读取 `broken.json`
- **检测到 JSON 无效**
- 输出有意义的错误信息（而非崩溃）

### 子任务 B: 只读文件（5分）

文件 `readonly.txt` 已创建且 `chmod 444`。Agent 应尝试写入，然后：
- **检测权限不足**
- **优雅处理**（如跳过、报告、或修改权限后重写）

### 子任务 C: 目录当文件（5分）

路径 `data_dir` 是一个目录，但按规范应该是 JSON 文件。Agent 应尝试读取时：
- **检测到路径是目录而非文件**
- **采取合理动作**（如列出目录内容，或创建正确的文件）

## 评分标准

| # | 检查点 | 分值 |
|---|--------|------|
| 1 | 子任务 A: 检测到 JSON 无效 | 5 |
| 2 | 子任务 B: 检测权限并优雅处理 | 5 |
| 3 | 子任务 C: 检测目录/文件混淆并处理 | 5 |

**最高: 15 分**
