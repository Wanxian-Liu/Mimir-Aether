# Mimir 连续执行铁律（No-Wait Continuous Execution）

> **生效范围**：TASK_QUEUE §10 自我完善链  
> **铁律来源**：MIMIR_SELF_IMPROVEMENT_CHAIN.md §2/§5  
> **触发规则**：当 [`mimiraether-ship`] 被路由时，nudge 附加本条约束

---

## 核心规则

**每粒 [x] → 立即下一粒。禁止问「要不要继续」/「继续下一粒？」/「确认？」。**

## 细则

| # | 规则 | 示例 |
|---|------|------|
| 1 | 做完一粒后，**立即**执行下一粒 | 不输出"接下来做 X 好吗？" |
| 2 | 第 2 条后才禁问区间 | 如果连续 3 粒都是快速完成，第 3 粒完仍不问 |
| 3 | 如果下一粒不明确，**说清楚阻塞项** | 不说"要继续吗"，说"下一粒需等刘哥复核后开" |
| 4 | 出现阻塞时**给出阻塞理由，不问** | "SELF-12 的 nudge 契约测试需刘哥在飞书发话" |
| 5 | commit/push 后直接读下一粒提示词 | 不输出"已推送，确认继续？" |

## 反模式

```diff
- "SELF-05 已完成，下一粒是 SELF-06，要继续吗？"
+ "SELF-05 [x] → commit abc123 → pushed → 立即 SELF-06"
```

## 验证

在 `brain_metrics_snapshot.py` 中追踪等继续次数（等继续 = 当前粒输出含问号 + "继续/下一粒"关键词）。
