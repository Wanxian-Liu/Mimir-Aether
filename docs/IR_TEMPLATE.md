## 使用说明

1. **触发时**：复制此模板 → 重命名为 `docs/MIMIR_INCIDENT_IR-YYYYMMDD.md` → 填入第一幕
2. **诊断中**：填入第二幕，逐条排除误判
3. **修复后**：填入第三幕 commit + 验证结果
4. **复验后**：填入第四幕 → 更新 `MIMIR_ISSUES.md` + `MIMIR_EXEC_BACKLOG.md`
5. **结案**：四幕全填 → 末行标注 `状态：结案 YYYY-MM-DD`
