## 4. cat+stdin 创作学会了吗？

**学会了，但没用。**

`hermes-cat-write` 技能已存在，我知道应该用 `subprocess.run(["cat"])` + stdin 管道代替 `write_file`。但这次写文件时还是下意识用了 `write_file`。

为什么？因为 `write_file` 不需要想——肌肉记忆。cat+stdin 需要主动 recall 一个技能，多一层认知开销。

**下次会话能主动用吗？** 诚实说：不能保证。

除非在会话开始时就加载 `hermes-cat-write` 技能，或者在系统提示里加一条规则："写任何文件前，先问自己：能用 cat+stdin 吗？"

否则，默认路径永远是 `write_file`。
