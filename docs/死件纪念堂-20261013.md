## 二、复用前须验证（**活件三问**·闸 = `scripts/dead_code_gate.py`）

**任何要写「复用既有 X」的场合，必须先跑三问并附读数**：

1. **① 有调用者吗？**（全仓扫 import / 调用点，剔除定义行）
2. **② 它的目标库/产物真的存在吗？**（`ls` 出来，报字节数）
3. **③ 运行时真在用吗？**（进程/日志/轨迹里找证据；查不到就说「没查到」）

**三问里任一为「否/查不到」⇒ 不许写「复用」**，只能写「迁入」或另起设计。

**闸用法**：

```bash
python3 scripts/dead_code_gate.py check memory_system     # 查单件（纪念堂 + 现值）
python3 scripts/dead_code_gate.py scan                    # 全量扫（有没有人新引用了纪念堂里的件）
```

**判定语义**（与 cron 退出码纪律一致）：**发现 ⇒ 打印 + exit 0**；非零只留给「闸自己没跑成」。

> **输入归一化 / 三态措辞 / 反例边界**（2026-10-13 修 · Mimir）→ 见本卡 §四。

## 四、2026-10-13 输入面归一化修复（**Mimir 执行** · 治「带路径调用假放行」）

**因**（审计方实测）：`python3 scripts/dead_code_gate.py check agent/memory_system.py` ⇒ 打印「不在纪念堂名录里」⇒ 被读成「未拦住 = 可复用」= **假放行**。根因 = 键空间是 `stem`、调用方输入空间是**路径**，两者无归一化桥 ⇒ 落 `else` 默认分支，而默认分支原措辞（「视为活件（本闸不拦）」）**主动**给出安全错觉。

**修法（外科手术式·不改退出码语义）**：① 输入归一化（`basename` → 去 `.py` → stem，`check`/`three` 共用）；② 默认分支三态化（措辞即语义）；③ 三态措辞收敛到**唯一出口** `note_for()`。

| 输入情形 | 输出措辞 | 退出码 |
|:--|:--|:-:|
| 在名录 | 🔴 已纪念堂化 ⇒ 「**禁止直接复用**」（+ 现值复测） | 0 |
| 不在名录·盘上找不到同名件 | 🚫 **件不存在**（名字写错 / 已删）——**不得**读成「安全」 | 0 |
| 不在名录·盘上有同名件 | ⚠️ **未登记 ⇒ 需人工确认 ≠ 安全** | 0 |
| 名录有登记·盘上无件（完整性副态） | 🚫 **件不存在**（名录/盘不一致） | 0 |

**同源计数（改一处必须改两处）**：脚本 `MEMORIAL_MODULES 5 + MEMORIAL_FUNCS 2 + FALSE_DEAD 2 = 9` == 本卡 A 段 5 + B 段 2 + C 段 2 = 9。

**四判据实测（2026-10-13 · rc 全 0）**：

| # | 命令 | 修后读数 |
|:-:|:--|:--|
| 正控 | `check persistent_store` | 「未登记 ⇒ 需人工确认 ≠ 安全」（+ 盘上找到 `agent/persistent_store.py`）——**非安全**表述 ✅ |
| 负控① | `check memory_system` | 「禁止直接复用」✅ |
| 负控② | `check agent/memory_system.py` | **归一化后与 stem 同判**「禁止直接复用」（修前 = 「不在名录」）✅ |
| 负控③ | `check 不存在的件` | 「**件不存在**」✅（不再静默当安全） |

**反例边界（本闸仍会骗人的地方 · 主动证伪实测）**：

1. **假拦截（保守方向）**：归一化只取 `basename`、**不核对目录** ⇒ `check docs/memory_system.py` / `check tools/memory_system.py`（两路径**均不存在**）实测被判成名录里的 `agent/memory_system.py` ⇒ 打印「禁止直接复用」。**修法（未做·挂账）**：输入含目录时与名录登记的相对路径做一次比对，不一致 ⇒ 打印「路径与登记位置不符」。本次**不修**（派单限定「只加归一化 + 措辞，不碰其他分支」）。
2. **②/③ 是近似**：`on_disk()` 以「全仓同名 `stem` 或 `def` 命中」判「盘上有件」⇒ 任一目录同名文件都会把 ② 判成 ③（措辞方向更保守，不是更安全）。
3. **作用域 = 登记表**：`scan()` 只扫**名录内**的件的引用 ⇒ 未登记的零引用件它看不见（本闸不是全仓死码分析器）。
4. **函数级口径不变**：`func_calls` 按「非 `def` 行命中」判调用 ⇒ 注释/字符串里提到函数名算「被调用」（假活）；`getattr(mod, "name")` 动态调用查不到（假死）。本次未改此口径。
