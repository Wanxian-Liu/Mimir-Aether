## 使用规则

1. 每次实跑命令后**追加一行**（窗口 + 时点 + 两数 + 占比），不覆盖历史行。
2. 判据达标与否只看**最新一行**，且必须先核该行窗口（日志轮转会改变分母）。
3. 连续两个观测窗不达标 = 退化 ⇒ 按 `AGENTS.md §5.1` 第 2 级处理（上闸门）。
4. 命令（唯一来源）：`grep -c 'parallel dispatch:' ~/.mimiraether/logs/agent.log`（分母）· `grep -c 'parallel dispatch: 0 read-only, 1 serial' ~/.mimiraether/logs/agent.log`（分子）
