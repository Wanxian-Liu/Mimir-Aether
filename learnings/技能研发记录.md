## 经验总结

### 技能研发模式
1. **识别可封装能力** → 从日常代码中发现通用功能
2. **理解原实现** → 读取源代码，提取核心API
3. **参考标准格式** → 学习现有SKILL.md结构
4. **封装为文档** → 用自然语言描述API和使用方法
5. **创建并验证** → 用skill_manage创建，skill_view确认

### 封装要点
- frontmatter必须包含: name, description
- 正文结构: 概述 → 功能 → 使用 → 示例 → 数据结构
- 保留关键实现细节供高级用户参考
- 包含CLI和Python API两种使用方式

### 质量保障
- 原始Python代码保留在`~/.mimiraether/skills_qa.py`
- SKILL.md作为技能文档和调用指南
- 两者互补，代码实现 + 文档说明
