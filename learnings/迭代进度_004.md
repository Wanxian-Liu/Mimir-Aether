## 二、新增模块详情

### 1. insights.py - 使用洞察系统

**功能**:
- 总体统计摘要 (会话数、Token总量、成本)
- 每日/每小时使用趋势
- Token分布分析 (input/output/cache)
- 成本分析报告
- 效率优化建议

**使用示例**:
```bash
python3 ~/.mimiraether/insights.py
python3 ~/.mimiraether/insights.py --days 30 --json
```

### 2. memory_fence.py - 记忆围栏

**功能**:
- 敏感信息检测 (API keys, passwords, tokens)
- 个人信息过滤 (email, phone, SSN, credit card)
- 记忆分类 (public/private/sensitive/restricted)
- 批量目录审计

**检测模式**:
- Critical: AWS Keys, Credit Cards, SSN
- High: OpenAI Key, GitHub Token, JWT, Passwords
- Medium: Phone Numbers, Generic Secrets
- Low: Email Addresses
