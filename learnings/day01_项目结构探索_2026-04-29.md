### 4. 关键设计模式识别

#### Hermes设计模式:

1. **自注册模式**: 工具模块在import时调用`registry.register()`
2. **单例事件循环**: `_tool_loop`全局持久化,避免"Event loop is closed"
3. **ThreadPoolExecutor**: 128 workers执行异步工具
4. **AgentResult dataclass**: 标准化返回结构
5. **WAL模式SQLite**: 高并发读写
6. **FTS5全文搜索**: 会话历史搜索

#### MimirAether新增设计:

1. **Decision Ring(决策环)**: `decision_ring.py` - 多角色决策机制
2. **Memory Fence**: `memory_fence.py` - 记忆安全隔离
3. **Strategy Matcher**: `strategy_matcher.py` - 策略匹配
4. **Memory System**: `memory_system.py` - 增强的记忆系统
5. **Delegate Subagent**: `delegate_subagent.py` - 子代理委托
6. **Async Bridge**: `async_bridge.py` - 异步桥接

## 设计模式

### 1. 异步驱动模式 (Hermes)
```python
# Hermes 使用 async/await 作为核心执行模型
async def run(self, messages) -> AgentResult:
    for turn in range(max_turns):
        response = await self.server.chat_completion(...)
        if response.choices[0].message.tool_calls:
            results = await self._execute_tools(...)
```

### 2. 自注册模式 (Hermes)
```python
# tools/registry.py
class ToolRegistry:
    def register(self, name, toolset, schema, handler, check_fn, ...):
        self._tools[name] = ToolEntry(...)

# tools/terminal_tool.py (模块级注册)
registry.register(
    name="terminal",
    toolset="core",
    schema={...},
    handler=terminal_handler,
)
```

### 3. 线程本地事件循环 (Hermes)
```python
# model_tools.py
_worker_thread_local = threading.local()

def _get_worker_loop():
    loop = getattr(_worker_thread_local, 'loop', None)
    if loop is None or loop.is_closed():
        loop = asyncio.new_event_loop()
        _worker_thread_local.loop = loop
    return loop
```

### 4. 单例注册表 (Hermes & MimirAether共用)
```python
# tools/registry.py
registry = ToolRegistry()  # 模块级单例
```
