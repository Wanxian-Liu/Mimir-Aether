## 核心贡献（一句话）

**分层 MPC 规划框架**——通过学习多时间尺度的世界模型 + 跨尺度潜状态匹配，在真实机器人非贪心任务上从 0%→70%（零样本），且**作为插件兼容多种世界模型架构**。

---

## 1. 问题

### 单层世界模型的两大根本挑战

1. **预测误差累积**：自回归 rollout 越长，误差指数增长
2. **搜索空间爆炸**：规划 horizon ↑ → 动作组合指数增长（curse of horizon）

### 为什么需要分层

- 长视界需要粗粒度推理，短视界需要精细控制
- 单层模型在这两者之间存在根本矛盾

## 2. 方法：HWM 分层规划框架

### 2.1 整体架构

```
高层规划 (to Goal):
  给定 z₁=enc(o₁), z_g=enc(o_g)
  使用高层世界模型 P^(2) + latent macro-actions l̂_{1:H}
  最小化 ℰ² = ||z_g - P^(2)(l̂_{1:H}; z₁)||₁
  → 产生子目标序列 z̃_i

低层规划 (to Subgoal):
  给定 z_current, z̃₁
  使用低层世界模型 P^(1) + primitive actions â_{1:h}
  最小化 ℰ¹ = ||z̃₁ - P^(1)(â_{1:h}; z_current)||₁
  → 输出动作序列执行
```

**关键设计**：高层和低层共享同一个编码器和潜空间——子目标直接在潜空间中传递，无需逆模型或技能学习。

### 2.2 低层世界模型

- 标准 JEPA 训练：teacher-forcing + 多步自回归 rollout 损失
- **沿用已有 backbone 的训练配方**（VJEPA2-AC / DINO-WM / PLDM）
- 保证性能提升来自分层规划而非改变底层模型

### 2.3 高层世界模型

**训练数据构造**：
- 从轨迹中采样 N 个 waypoint 状态（N < T）
- 每个高层 transition = (waypoint s_tₖ, 中间动作子序列 a_{tₖ:tₖ₊₁}, 下一个 waypoint s_tₖ₊₁)

**动作编码器 A_ψ**：
- 将 waypoint 之间的低层动作序列编码为 **latent macro-action** l_tₖ
- 使用 Transformer + CLS token 投影到潜动作空间
- 对比 delta-pose（净位移）：delta-pose 会丢失非贪心路径信息

**共享潜空间**：
- 高层和低层共享同一个 encoder E
- 高层预测目标 = 下一个 waypoint 的潜表示 ẑ_{tₖ₊₁}
- 损失：L_tf = (1/N) Σ ||ẑ_{tₖ₊₁} - z_{tₖ₊₁}||₁

## 3. 实验：三大领域 × 三种世界模型

### 3.1 Franka 真实机器人（VJEPA2-AC + HWM）

| 任务 | 单层 | +HWM | 提升 |
|------|------|------|------|
| Pick&Place (有 oracle 子目标) | 80% | 80% | 0 |
| Pick&Place (仅最终目标) | **0%** | **70%** | **+70pp** |
| Drawer | 30% | 70% | +40pp |

**对比 VLA 模型**（π0.5-DROID 在 pick&place cup 上 68% vs HWM 70%），且 VLA 用 77× 更多交互数据训练。

### 3.2 Push-T 长视界（DINO-WM + HWM）

| 任务距离 d | DINO-WM | +HWM |
|-----------|---------|------|
| d=25 | 84% | **89%** |
| d=50 | 55% | **78%** |
| d=75 | 17% | **61%** |

规划计算量减少 **3×**。

### 3.3 Diverse Maze 导航（PLDM + HWM）

| 难度 | PLDM | +HWM |
|------|------|------|
| Easy (D∈[5,8]) | 100% | 100% |
| Medium (D∈[9,12]) | 63% | **95%** |
| Hard (D∈[13,16]) | 44% | **83%** |

规划计算量减少 **4×**。

## 4. 分析洞察

### 4.1 Latent Actions vs Delta-Pose

| 高层动作表示 | Action Cos↑ | Action L1↓ |
|-------------|------------|-----------|
| Delta Pose（净位移） | 0.80 | 0.088 |
| **Latent Action（学习）** | **0.88** | **0.080** |

→ 学习的潜动作能编码完整的非贪心动作序列结构，delta-pose 丢失了路径信息。

### 4.2 长视界预测精度

- 短视界（≤1s）：低层模型更准
- 长视界（≥1.5s）：高层模型单步预测优于低层模型 16 步自回归
- **分层策略=各取所长**：高层提供长期引导，低层处理短期精度

### 4.3 子目标质量与潜动作维度

- 潜动作维度太低 → 高层规划无效
- 潜动作维度适中（=4）→ 子目标偏贪心，低层可执行 → **最优**
- 潜动作维度太高 → 子目标需要复杂非贪心执行 → 低层执行失败
- 关键洞察：**"恰到好处的表达能力"**比"最大表达能力"更好

## 5. 关键设计原则

1. **共享潜空间是分层规划的最小接口**——不需要逆模型、技能库、目标条件策略
2. **高层模型减少自回归步数**——单步预测替代多步 rollout → 减少误差累积
3. **动作编码器压缩搜索空间**——4维潜动作 vs 原始动作序列
4. **与底层模型解耦**——HWM 是插件式抽象，不修改 backbone 训练
5. **子目标不需要完美重建**——粗粒度语义（接触事件、运动方向）足够

## 6. MimirAether 映射

### 关键可迁移概念

1. **战略层 + 战术层**
   - 战略层：阶段级任务分解，产生子目标
   - 战术层：子目标内执行工具调用链
   - 接口：共享任务表示（状态向量 + 约束向量）

2. **高级规划抽象**
   - 类比 latent macro-action：将多步工具调用序列压缩为"意图向量"
   - 减少战略层搜索空间

3. **子目标生成与质量**
   - "恰好够用"抽象级别：太抽象→不可执行，太具体→失去分层优势
   - 类比：阶段描述粒度——"重构认证模块" vs "修改 auth.py 第 47 行"

4. **长视界误差管理**
   - 短视界任务（≤3步）用战术层精确规划
   - 长视界任务（≥5步）用战略层粗粒度引导
   - 类比：单文件重构 vs 跨模块架构变更

5. **错误预算分配**
   - 战略层容忍更高误差（只提供方向）
   - 战术层需要精确（具体执行）
   - 与 HWM 预测精度曲线一致

6. **Pipeline 集成**
   - 现有 brainstorming → plan → execute → verify → ship
   - 映射到 HWM 两层：战略层(前两步) / 战术层(后三步)
   - 重新规划触发：每 K 步后或 verify 失败时
