## 问题2：SKILL.md 格式分析

### 标准格式结构

```yaml
---
name: <技能名称>
description: <简短描述>
version: <版本号>
author: <作者>
license: <许可证>
metadata:
  hermes:
    tags: [<标签列表>]
    related_skills: [<相关技能>]
---

# 技能标题

## 概述
...
```

### 必需字段
- `name` - 技能唯一标识
- `description` - 一句话描述用途

### 可选字段
- `version` - 版本号
- `author` - 作者
- `license` - 许可证
- `metadata.hermes.tags` - 标签
- `metadata.hermes.related_skills` - 相关技能

### skills_qa.py 封装可行性

| 原功能 | 封装方式 | 复杂度 |
|--------|----------|--------|
| 目录结构检查 | 描述说明 | 无 |
| YAML解析验证 | 描述验证规则 | 低 |
| 过期检测逻辑 | 描述 + CLI命令示例 | 低 |
| 报告生成 | 描述输出格式 | 无 |

### 封装策略

**方案A：纯描述式 SKILL.md**
```
保留Python代码执行能力，通过描述指导如何使用工具
```

**方案B：混合式**
```
SKILL.md作为元数据 + Python脚本作为执行层

### Phase 3: 封装 skills_qa.py 为 SKILL.md

#### 原代码核心功能

```python
class SkillsQA:
    REQUIRED_META_FIELDS = ["name", "description"]
    EXPIRY_THRESHOLD_DAYS = 30
    
    def validate_skill_md(self, skill_name): ...
    def check_skill_expiry(self, skill_name): ...
    def run_qa_check(self): ...
```

#### 封装后的 SKILL.md 技能

```markdown
---
name: skills-qa
description: Validate skills directory structure, SKILL.md format, and detect expired skills. Use when auditing, maintaining, or ensuring quality of skill repositories.
version: 1.0.0
author: MimirAether
license: MIT
metadata:
  hermes:
    tags: [skills, QA, validation, quality, maintenance]
    related_skills: []
---

# Skills Quality Assurance

## Overview

Automated validation for skill directories and SKILL.md format compliance.

## Validation Rules

### Required SKILL.md Fields
- `name` - Unique skill identifier
- `description` - Brief purpose description

### Optional Fields
- `version` - Semantic version
- `author` - Creator
- `license` - License type
- `metadata.hermes.tags` - Classification tags

## Expiry Detection

Skills are marked expired if not updated in 30+ days (based on file mtime).

## Usage Examples

### Validate a skills directory
```bash
python -c "
import yaml
from pathlib import Path

skills_dir = Path('~/.openclaw/projects/MimirAether/skills')
for skill_dir in skills_dir.iterdir():
    skill_md = skill_dir / 'SKILL.md'
    if skill_md.exists():
        content = skill_md.read_text()
        # Check frontmatter format
        if content.startswith('---'):
            print(f'OK: {skill_dir.name}')
        else:
            print(f'INVALID: {skill_dir.name} - no frontmatter')
"
```

### Find expired skills
```bash
find ~/.openclaw/projects/MimirAether/skills -name "SKILL.md" -mtime +30
```

## Integration
