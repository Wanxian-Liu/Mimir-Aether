# 内部会议（Internal Council）

> 刘哥 2026-11-11 立：以后说「开内部会议」，**不用他提醒**就自动走完全套。
> 方向以他为主；技术判定我做完再报，不上交。

## 0. 一句话流程

戴帽当主持人 → 按议题选 3 席（必含 1 席反对角度）→ 政策落盘 → 平行派单（工具集裁剪）→ 收齐 → **我自己复算每一条读数** → 终裁 → 落会议卡 → 更新四方建议卡。

## 1. 硬触发

用户说以下任一句，**不再问「要不要选角色/走什么流程」**，直接开：

`开内部会议` · `开个会` · `内部会` · `戴帽评审` · `多角色评审` · `让几个角色看看 X`

唯一需要问的情况：**议题本身歧义**（不知道要评什么）——问议题，不问流程。

## 2. 主持人戴帽（第一件事，不许跳）

我自己也是参会者，且是**有裁决权的主持人**。按议题在 `~/wiki/entities/Agency-Agent角色索引.md` 选帽，**全量读完**（禁只读 frontmatter），回执三件套写进会议卡 §主持人段：


**选角三条硬规则**

1. **3 席**（≥3 才有独立复算价值；>4 收益递减、上下文爆炸）。
2. **必带 1 席反对角度**——不是客气话，是任务书里写死：*「你的任务是找出本提案会失败的理由，并说明为什么现有读数为 0 不代表缺陷」*。允许它推翻我的结论，正是它上次推翻了我三条核心读数。
3. **禁两席同分类同角色**——同质席位只会互相附和（今天 3 席中 2 席独立发现了同一个 bug，第 3 席发现了另一个，这才是价值）。

## 4. 政策与事实落盘（子代理没有我的上下文）

派单前必须先落两个文件，这是子代理**唯一**的共享输入：

- `~/.mimiraether/tmp/council-<slug>-brief.md`——议题、已确证读数、待判选项、禁止事项
- `~/.mimiraether/tmp/agency-cards-readable/`——把选中的角色卡 **copy 到可读路径**（`read_file` 对 `~/.openclaw/**` 是白名单拦截的，子代理会读不到卡）

## 5. 派单（工具集裁剪 = 唯一有效的禁令）

**文字禁令对子代理无效**（实测：明令「不许写文件」，两席仍各写了回执）。只能靠工具集裁剪 + 事后核轨迹。

推荐 toolsets：`["terminal", "search"]`（只读取证）；**不给** `file`。

任务书必须含：

1. 角色卡**绝对可读路径** + 要求**全量读完**、**逐字引用 ≥3 条规则**、**说明用到的方法段名**
2. 允许/禁止的命令白名单（只读；禁写盘、禁 git 提交）
3. 明确「给你的每个数字都要能附可跑命令」
4. 要求结构：结论 / 依据（带命令+读数）/ 与我的分歧点 / 你没验到的
5. 反向要求（仅反对席）：找失败理由

**发单后必做**：核每个子代理的轨迹，出现 `write_file` / `execute_code` / `git commit` 立刻在会议卡记违规，并核它写了什么（不许忽略）。

### 已知能力边界（按实测，不按文档）

| 项 | 文档说 | 实测 |
|---|---|---|
| `execute_code` | 子代理不可用 | **可用**（两席各用了 5-6 次） |
| `read_file` 读 `~/.openclaw/**` | 可用 | **被白名单拦** ⇒ 必须先 copy |
| 文字禁令 | 应遵守 | **无效** ⇒ 靠 toolsets |
| 子代理 HOME | 继承 | `~/.mimiraether` ⇒ 路径写死 `$HOME=<用户主目录>`（取值用 `echo $HOME`，禁把真实主目录写进卡） |
| 并行上限 | — | 3 席 / 单批，实测 130~200s 收齐 |

## 6. 裁决纪律（这一节最贵）

**席位给的数，我自己重算一遍再采信。** 实测：两席各自给出的读数里，一席把一个「存在的文件」报成「不存在」，另一席报的数我复现不出——**独立执行者会独立犯同类错**，两个都说对不等于对。

四条：

1. **数字由命令产出，禁手算**（手算 819−54=765，实测 771；6 张只有 1 条边不越线）
2. **禁凭记忆写参数名**（写过 `--check`，实际 `--selftest`；跑复算时才暴露）
3. **量具自身要证**：`--selftest` 正反两向 + **变异验证**（改回旧算法必须失败）。变异必须**隔离**——今天两次犯：变异二没还原变异一，跑的是叠加态，两个变异给出逐字相同的读数。判据：**这个读数只可能由这个变异产生吗**
4. **口径先对齐再比数**：同一指标两处实现，先验「是不是同一批数据」（今天 ② 单文件 1353 / ⑤ glob 含转档 1687，delta +334）

## 8. 会议卡（必须落盘，禁只在对话里开会）

路径：`~/wiki/discussions/<日期>-内部会议-<议题>.md`，`status: mimir`（待我确认后改）。

必备段：

```
## 0 主持人帽（回执三件套）
## 1 议题与已确证读数（每条附命令）
## 2 三席组成（角色名 + 卡真实路径 + 分类）
## 3 各席结论（分歧点单列，不许合并成"共识"）
## 4 我的复算（席位读数 vs 我实测，不一致必写）
## 5 终裁（Q1/Q2/Q3 逐条：选哪个 + 为什么 + 判据）
## 6 请裁上收（要谁批什么）
## 7 复盘（被推翻的读数 / 我的错 / 未验项）
## 8 交棒（下一段第一件事）
```

**双链硬规则**：新建卡正文 ≥2 个 `[[双链]]`，且**链接目标必须真实存在**（今天造过 3 条死链、2 条字面量链；判据 `wiki_card_links.py --card <卡>` rc=0）。

## 10. 常见死法（今天全部真实踩过）

| 死法 | 症状 | 修法 |
|---|---|---|
| 同质席位 | 三席结论一致、像回声 | 塞一席反对角度 |
| 采信未复算 | 席位报错数，我直接写进卡 | §6 第 1 条 |
| 手算当读数 | 差 6，卡上数字全废 | 命令产出 |
| 量具无自证 | 尺子坏了还用它论证 | selftest + 变异（隔离） |
| 假阴性当结论 | 「不存在」其实在别处 | 报「不存在」前先声明搜索面（今天 `graph_leg` 报 0，实际 423 行在 `~/.hermes`） |
| 凭记忆写参数 | 卡里命令跑不通 | 落卡前现跑 |
| 绕钩子 | `core.hooksPath=/dev/null` 后忘了补验 | 必须用真钩子重跑一遍 |
| 只在对话里开会 | 重启即丢，无法复核 | 会议卡落盘 |

## 11. 交接

会议卡 `status` 流转：`mimir`（进行中/待我确认）→ `hermes`（送四方复核）→ `刘哥`（需人裁）→ `resolved`（**只有判据可跑且过他源复核才可标**）。
