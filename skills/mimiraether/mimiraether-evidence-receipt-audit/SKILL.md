# 证据型回执 · 九查

## 何时用
- 架构会/审计轮的**交叉审视**（审他方回执）· 复核他方读数 · 「他方声明已实测」类完工件
- 不适用：本侧自写回执（自检 delta≡0，走 §8.3 L2 他源复核）

## 九查（每条 = 一行命令 + 判据；前四条已两犯）
1. **行首锚**：`grep -cE '^冒烟档位: [①②③④]' <件>` —— 写成 `### 冒烟档位:` 或 `**冒烟档位:**` ⇒ **0 命中**（我方一轮 + 妹妹二轮已各犯一次）
2. **契约字段（未锚定）**：`grep -c '重跑命令:'` / `grep -c '复算数字:'` —— 字段前带 `### ` 也能命中；**别用行首锚**去判这两条（会误判）
3. **引证行号核**：对每条 `L<n>` 断言跑 `grep -n <关键字> <文件>` 核真值；偏 ≥1 ⇒ 记「引证错位」
4. **文本真源定位**：引用只写文件名（如 `AGENTS.md`）⇒ 先 `grep -rl` 定位真路径（同仓常有多份同文本，四方会拼出互斥行号）
5. **回退路径存在性**：`git -C <dir> rev-parse --show-toplevel` rc=128 ⇒ 该目录**无 git** ⇒「git revert」= 幻报；再查 `*.bak*`
6. **判据 CLI 可执行性**：抽命令里的 CLI ⇒ `command -v <cli>`；rc≠0 ⇒ 该条「实测」**不可能**由该命令产生
7. **时间窗**：计数类判据必须带窗口（无窗计数 ⇒ 恒真或假阳性；`+1` 若无窗口 = 非判据）
8. **读整行**：别只读数字段 —— 实测 `EXIT code=9 elapsed=0s（脚本主动退出·非崩溃非硬杀）`，括注**否掉**了「SIGKILL」结论
9. **被审件漂移**：`stat -c %y <被引文件>` vs 回执落款；若会期内被改且无版本控制 ⇒ 要求定稿前 `sha256sum` 三件并写进决议
10. **前提实测（转述的系统行为一律要本机实证）**：被审件声称的语言/库行为（"无上限 join"、"3.12 才支持"、"会一直等"）⇒ 用**本机解释器 + 标准库源码行**实测（`importlib.util.find_spec` + 读 `asyncio/runners.py`/`base_events.py` 行号），别接受转述。本案实证：3.12.13 `Runner.close()` 传 `constants.THREAD_JOIN_TIMEOUT = 300` ⇒ **有界**，推翻「无上限 join」。（同类：读源码确认 `shutdown_default_executor` **无幂等短路** ⇒「协程内先关一次」挡不住 close 的二次 join = 反证某"更小改法"）
11. **同向修复重叠（最小改动视角的第一问）**：被审件要"修 X"时，先查**同一条路径上近期是否已有修复**——`git log --since=<N> -- <文件>` + 运行期指标复测（`journalctl … | grep -cE 'Killing process|Failed with result'` + Stopping→Stopped 耗时）。若已覆盖，最小改动答案常是「**不实施**」；少了这一查，会给出"再改一处"的方案（双修同一病 + 白增生产入口风险面）。

## 坑（实测）
- **期望值 ≠ 读数**：`期望 …count +1` = 未过闸（§8.5：形容词/期望 = 未过闸）
- **负控不成立 = 判据不合格**：两个**串行** `flock -n <f> <cmd>` 必然都成功 ⇒ 无「败」侧；要出败必须持锁侧真实持有
- **有行 ≠ 被硬杀**：SIGKILL 语义上留不下任何行；「有行」本身否掉「硬杀」
- **锁残留**：脚本里 `grep -c '[Ll]ock'` = 0 ⇒ 无自建锁；POSIX 锁由**内核**在进程销毁时释放（含 SIGKILL）
- **OOM 与本案**：先比**时间窗**（`journalctl -k` 时间戳 vs 崩溃窗）——「路径已开火」≠「本案死因」，别把机制事实升级成因果结论
- **角色帽**：审票前换帽（不得重复一轮帽）并**全量读卡**，回执带 `角色:`/`卡路径:`/`引用规则N:` ≥3
