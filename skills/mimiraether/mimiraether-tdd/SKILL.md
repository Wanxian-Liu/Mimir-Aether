# MimirAether TDD

## 描述

MimirAether测试驱动开发工作流 - 集成TDD最佳实践，引导用户完成红-绿-重构循环。

## 核心功能

- **测试先行**: 生成功能测试代码模板
- **RED阶段**: 运行测试验证失败状态
- **GREEN阶段**: 实现最小代码让测试通过
- **REFACTOR阶段**: 重构代码同时保持测试通过
- **测试覆盖报告**: 生成当前代码的测试覆盖情况
- **回归保护**: 每次修改后自动运行相关测试

## 使用场景

- 新功能开发遵循TDD流程
- 现有代码的测试覆盖补充
- 重构前的测试保护网建立
- Bug修复时先写复现测试
