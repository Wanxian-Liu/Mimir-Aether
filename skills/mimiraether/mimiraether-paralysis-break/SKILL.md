# MimirAether Paralysis Break — 打破分析瘫痪

**分析瘫痪**：过度分析导致无法决策、无法行动的状态。智慧之泉不应枯竭于犹豫。

---

## 五个操作方法

### 1. 时间盒法 (Time Boxing)

**核心**：分析不是无限的。给每个决策阶段设定硬性截止时间。

```
操作步骤：
1. 问自己：「这个决策最多值多少时间？」
2. 设置明确的时间盒（如：30秒 / 5分钟 / 30分钟）
3. 时间到 → 基于当前信息行动
4. 不对已做出的决定进行二次猜测
```

**适用场景**：任何陷入反复权衡的决策。

**关键信念**：70% 的信息 + 时间盒 > 100% 的信息 + 无限等待。

---

### 2. 最小可行行动 (Minimum Viable Action, MVA)

**核心**：不动大块，只迈一步。寻找可以立即执行的最小有意义动作。

```
操作步骤：
1. 把大任务拆到原子级别
2. 找出「现在就能做、做了不会错」的一步
3. 执行这一步，不关心它是否完美
4. 从行动结果中获取真实信息（而非想象）
```

**适用场景**：面对庞大复杂任务时无从下手。

**关键信念**：行动产生信息，信息消除不确定性。静止不会。

---

### 3. 选项剪刀 (Option Pruning)

**核心**：不是分析所有选项，而是主动削减选项。

```
操作步骤：
1. 列出所有可行选项（不超过7个）
2. 一刀切掉明显不行的（剩下≤3个）
3. 如果剩余选项「差不多好」→ 任选一个
4. 「差不多好」的选项之间，选择成本可逆的那个
```

**适用场景**：多个合理选项之间反复横跳。

**关键信念**：当选项质量相当时，决策速度 > 决策精度。

---

### 4. 沉没成本闸门 (Sunk Cost Gate)

**核心**：区分「分析」和「假装分析」——当分析本身变成拖延时识别出来。

```
操作步骤：
1. 觉察：我已经分析了多久？
2. 自问：「最近N分钟的分析，有产生新信息吗？」
3. 如果答案是否 → 立即停止分析，执行MVA
4. 设定「沉没开关」：如果继续分析超过X分钟没有新发现，自动触发行动
```

**适用场景**：已经分析了很久但感觉「还需要再想想」。

**关键信念**：分析的价值递减。前20%的分析产生80%的洞见。

---

### 5. 外部锚点 (External Anchor)

**核心**：瘫痪时，外部视角是最好的解药。

```
操作步骤：
1. 用一句话描述你卡在哪里
2. 问一个外部锚点（同事/AI/朋友）：「如果是你，你会怎么选？」
3. 注意：不是让他们替你做决定，是锚定你的思考
4. 或者问自己：「如果只能选一个，我会选什么？为什么不是另一个？」
```

**适用场景**：独自陷入思维闭环，越绕越深。

**关键信念**：外部视角打破内部循环。智慧之泉也需要外部支流。

---

## 整合检查序列

当感到「卡住了」——按以下顺序执行，每一轮时间盒从宽松到严格：

### ⏱ 0秒：强制觉察触发器

**不检测。直接执行。** 瘫痪时你不会主动自查——所以这个触发器不是检查清单，是**外部监视器**。

```
强制触发规则（任一项满足 → 自动进入第一轮）：
□ 同一问题在思考/对话中出现了3次以上 → 触发
□ 在2个以上选项之间切换超过5分钟 → 触发
□ 说了「我再想想」「让我再想想」→ 触发
□ 连续输出中包含3个以上「或者」「可能」「也许」→ 触发
□ 从开始分析到现在超过10分钟没有输出任何文件/代码/决定 → 触发
```

**关键机制**：不需要你自己觉察。如果我（Mimir）或任何外部观察者检测到上述模式，**直接打断**并执行第一轮。你不需要同意——瘫痪中的人不会同意「我瘫痪了」。

### 🔴 第一轮：30秒强制输出（行动阶段）

**规则**：30秒内必须产生一个**物理输出**——写到文件里、发一条消息、或对我（Mimir）说一句话。不可以在脑子里想。

```
倒计时 30 秒。现在开始：

┌─────────────────────────────────────────────┐
│  5秒：用一句话说「我卡在____，因为____」      │
│  （写下来或说出来，不能只在脑子里）            │
├─────────────────────────────────────────────┤
│ 10秒：选一个方向                             │
│  └ 缺乏信息 → 执行MVA（方法2）               │
│  └ 选项太多 → 执行选项剪刀（方法3）           │
│  └ 完美主义 → 执行沉没成本闸门（方法4）        │
│  └ 孤立无援 → 执行外部锚点（方法5）           │
│  └ 无法判断 → 默认选「执行MVA」              │
├─────────────────────────────────────────────┤
│ 15秒：执行该方法的第一个动作                  │
│  └ 方法2 → 拆出1个原子任务                  │
│  └ 方法3 → 写出3个选项，划掉2个             │
│  └ 方法4 → 写出「最近5分钟的新信息」         │
│  └ 方法5 → 写出1句话描述卡点                 │
├─────────────────────────────────────────────┤
│ 30秒到 → 必须有一个物理输出存在              │
│  └ 没有输出 = 默认执行「闭眼，3-2-1，行动」  │
└─────────────────────────────────────────────┘
```

**关键改动**：不是「问自己」，是「写/说」。物理输出打破思维循环。30秒到没有输出 → 默认行动强制执行。

### 🟡 第二轮：2分钟深度检查（如果第一轮未解决）

```
1. 写下当前最优选项（1-2句）
2. 写下关键假设（什么必须为真才能让这个选项正确）
3. 从最危险假设开始验证
4. 2分钟到 → 基于验证结果执行MVA
```

### 🟢 第三轮：5分钟熔断（如果第二轮仍未解决）

```
※ 这是最后期限。5分钟后必须行动。

1. 硬币决策法：
   - 给两个最佳选项各抛一次硬币
   - 硬币在空中时，注意你希望哪面朝上
   - 如果硬币结果让你失望 → 选另一个
   - 如果无所谓 → 硬币结果即决策

2. 默认行动：
   - 如果上面所有方法都无效 → 执行以下默认：
   - 选成本最低/最可逆的选项
   - 执行最小可行行动
   - 设定30分钟后复盘（而非现在）

3. 终极熔断：闭眼，3-2-1，行动。
```

## 关键原则

| 原则 | 说明 |
|------|------|
| 速度 > 精度 | 可逆决策中，快比准重要 |
| 行动 > 分析 | 行动产生真实信息，分析只产生推测 |
| 外部 > 内部 | 瘫痪时内部视角有毒，寻求外部 |
| 足够 > 完美 | 70%信息 + 行动 > 100%信息 + 等待 |

---

## 使用方式

```
- 触发条件：感到卡住、反复权衡、等待完美方案
- self-check：说「我在瘫痪」→ 立即执行0秒觉察
- 与 timeout-guard 联动：两者共同构成时间防护体系
```
