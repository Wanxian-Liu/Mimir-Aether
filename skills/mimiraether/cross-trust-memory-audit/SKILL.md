# 跨信任边界记忆审计 SOP

## 何时用
- 被派「审某方（Hermes/OpenClaw/Loki/刘哥）的记忆体系」：三层配置（SOUL/AGENTS/MEMORY/USER）+ Wiki 记忆卡。
- 铁律：**只读审计**——不改被审对象任何文件；发现即记录；唯一写盘产物=报告 + 派单卡回执段。

## 关键坑（先读，省 3–5 轮）
1. **`read_file` 被 path whitelist 拦 `~/.hermes` 与 `~/.openclaw`（只读也拦）** ⇒ 取证一律走 `execute_code` 内 Python `open()`；`wiki/` 路径 `read_file`/`write_file`/`patch` 均可用。
2. 拦截后**必须披露取证通道**（报告里写「经 execute_code 读取，非声称读过」）——否则等于伪造真读凭证。
3. `execute_code` 命令串里出现 `| sh`（哪怕只是表格头 `| sha`）、`.env`、`/usr/` 片段会被安全扫描整块拒；避开这些字面量。
4. CJK 文件**上限判断用 `len(text)`（字符）不是 `os.path.getsize`（字节）**——差 2–3 倍会误判超限。
5. `state.db.sessions.started_at` 是 **epoch 浮点**，要 `datetime.fromtimestamp` 才能按日聚合。
6. 早写盘、后补全：先 `write_file` 出报告骨架（≤3KB），再逐段 `patch` 替换 `<!--APPEND-->` 哨兵追加——长内容一次写会 JSON 截断。

## 六维判据（操作化）
| 维 | 怎么判 |
|---|---|
| ①真伪 | 每条声称 CLAIM/EVIDENCE 分列；EVIDENCE 取**产物本体**（config/db/文件/端口/mtime），禁引作者转述；**必配正控**（同量具测一个已知为真的事件，证明量具活着） |
| ②时效 | (a) 已办未标：grep「待改/待做」→ 查对应仪器是否已存在；(b) 易腐事实入长期记忆：PID/水位/进度快照/karma/星数/行数；(c) 距今 >14 天且无复核读数 |
| ③冲突 | 成对引用（A 文件 X 行 ↔ B 文件 Y 行）+ 盘上仲裁（谁与 config/实测一致）；**权限类冲突不自决**，上报 |
| ④重复 | 三重：md5 字节级 / 文件名规范化后同 / 中文词集 Jaccard（≥0.35 报，≥0.9 判真重复） |
| ⑤格式 | 以「出生宪法 draft §13.1/13.4」或派单口径必填字段；统计 无FM率 / 缺字段率 / updated≠mtime率；单列「主战场」 |
| ⑥闸门 | 抽查 3–5 例，问「**若它失效，谁会报警？**」答不出=纪念品；有仪器者查 last_run |

## 固定清单（10 条，复审同跑）
1. 量具存活（先 stat 全部目标 mtime + cron last_run）→ 才允许下「缺失/为 0」结论（RS17）。
2. 权威顺序对账：`config.yaml` 顶层 `model:` + `state.db` 近 7 日 model 分布 ↔ 三处「主模型」文字。
3. 上限对账：`memory_char_limit`/`user_char_limit` ↔ 实占字符 ↔ 文中声明上限。
4. 权限类条目 grep「先问/授权/可直接执行/必须审批」→ 查同题双写。
5. 易腐事实正则：`PID|水位|仅剩|领先 .*commit` + 计数类。
6. 重复三扫（md5 / 文件名 / Jaccard）。
7. 格式三率（含 readings/ 与 entities/books/ 单列——常见「模板空壳群」）。
8. **外存链水位**：Memory/USER 占用率 + 各层总卡 mtime 差 ⇒ 判「分流是否真在跑」（常见根因：仅水位/事件触发 ⇒ 永不触发）。
9. 跨方接口类记忆必须落到**对方盘上**取证（本地笔记会滞后于对方脚本演进）。
10. 无外网/无凭证 ⇒ 标 `UNVERIFIED` + 复算路径，**禁**写成「疑似错误」。

## 报告体例
头部=纪律声明+角色真读凭证（≥3 条规则原文）；主体=逐层 + **通过项正控单列**（防只报错的偏置）；清单=P0(错误/冲突)/P1(过期)/P2(重复)/P3(格式) + 每条**复算路径** + 等级理由；建议=分批（可独立验收/拒绝）+ **明确「不建议做的事」**（防过度修复）；尾部=规程沉淀 + 附录（脚本、UNVERIFIED、审计者自评）。

## 高价值经验（实测分布）
- **「事实层 vs 状态层」分离统计**：事实层（路径/机制引用）命中率高，**状态层（模型/进度/计数）系统性滞后** ⇒ 审计预算压状态层。
- **同源回声检测**：三处记忆互证同一结论时先回溯「谁读过谁」——三写不因同源而变强（实测：三处「主模型」实为一条 9/23 笔记的三个副本 + 盘上为另一种模型）。
- 交付：报告落盘 → 派单卡 `patch` 追加「回执 · <我方>（status: 对方）」段 → `git add` 指定文件 commit（`HOME=$HOME` 供作者身份）。
