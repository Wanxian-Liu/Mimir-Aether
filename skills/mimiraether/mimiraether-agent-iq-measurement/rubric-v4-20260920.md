## 0. 三条计分铁律（沿用 skill §5，v4 继续生效）

1. **仪器缺失 ≠ 性能退化**：量具 `instrument_status ∈ {live, absent, stale}`（读端 `agent/experience_buffer.py`
   已实现）；`absent/stale` ⇒ 该维 **N/A + 分母剔除 + 单列「仪器债」**，**不得记 0 分**。
2. **只读量具的开关不得与可写执行器同组**：量具组 `MIMIR_FEEDBACK_COLLECTOR`（常开，零写副作用）
   与执行器组 `MIMIR_AUTO_ANALYSIS` / `MIMIR_AUTO_EVOLVE` / `MIMIR_AUTO_TUNER` / `MIMIR_AUTO_1C_POLICY`
   （维持 0，分层授权后再开）互斥（单一真源 `agent/feedback_collector.py::switch_semantics()`）。
3. **每条分数必须带盘上判据**（文件路径 / commit / 计数 / 闸读数），且**无 cost 字段的分数不进表**。

## 2. v3 → v4 变化（为什么这么改）

| 维度 | v3 | v4 处置 | 理由 |
|:--|:--:|:--|:--|
| 模型推理/通用能力 | 隐含进各维 | **剔除** | 外生常量（换模型就变），不是「我支配四肢」的能力 |
| #8 意图理解（10%） | 单列 | **降为 B2 子项** | 规则式 IntentPredictor 的可测部分属工具面契约 |
| #9 模型路由（5%） | 单列 | **剔除** | 基础设施配置，不属协调能力 |
| #5 Prompt 优化（10%） | 单列 | **降为 B2 子项** | 与工具面 ACI 同源（工具质量提示 / read-only 纪律） |
| #7 上下文管理（10%） | 单列 | **降为 A2 子项** | 压缩/续跑归根到底是「断点自检」的一种 |
| #1 学习能力 / #3 反馈收集 | 15% + 10% | **合并为 B3（8%）** 且以量具 live 为前提 | 反馈环断 5 周时这两维却在涨分 ⇒ 计量方式错了 |
| 闸/回滚/记忆 | 散落（#6 错误恢复等） | **升为 A 组 55%** | 刘哥定调：评价的是「支配四肢」 |
| — | 无 | **新增 C1 成长斜率 15%** | 「昨天做不到今天做到」才是婴儿→男子的证据 |

## 3. 打分流程（v4）

1. 先跑 7 条硬前置（skill §1）；**任一量具 absent/stale ⇒ 只报「仪器状态」，不出总分**。
2. 逐维填「盘上判据」列；无判据 ⇒ N/A（不是 0）。
3. C1 必须逐条列动作 + 对照证据。
4. **自评只作草稿**：需 ≥1 个异源 agent 独立重打（裁判不得同源同模型）。
