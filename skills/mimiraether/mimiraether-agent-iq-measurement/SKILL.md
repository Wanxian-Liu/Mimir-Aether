# 测 Agent 综合智商：外部标尺 + 自评的硬前置

> 建立 2026-09-19（IQ 第三次复评 · 首次下跌 5.62→5.585 后固化）。
> 用途：**任何「打分 / 复评 / 你进化了么」类任务，先读本技能，再动手。**

## 0. 第一原则（本次实证换来的）

> **修好尺子 ≠ 变聪明；而尺子坏掉时会静默表现为「没有反馈」。**
> 实证：反馈环 `feedback_events.jsonl` 停摆 35 天无人发现 ⇒ 直接导致 #3 维度 5.5→4.5，总分首次下跌。
> 而同期「让尺子可信」的产出（门禁治本/记忆保真/卫生闸）在 10 维表里**一分不加**。

## 1. 打分前的 7 条硬前置（任一不过 ⇒ 只报「仪器状态」，不出总分）

| # | 前置 | 判据（可执行） |
|:-:|:--|:--|
| 1 | **量具存活** | `test -e <指标文件>` × 全部量具；缺失 ⇒ 标 **N/A，不标 0**（「无数据」≠「无失败」） |
| 2 | **反背题** | 分数必须用 **held-out 题集**报；旧固定题集降级为「回归对照」，**不再作为能力证据** |
| 3 | **成本口径** | 每维分数附 token/秒/元；**无 cost 字段的分数不许进表**（否则重演「#7 触顶 8.0 vs 实测 p50 13.6s」） |
| 4 | **异源裁判** | 自评须由 **≥1 个异源 agent** 独立重打；**裁判不得同源同模型**（self-attribution bias 已实证：某厂商自评通胀 CI [35.9, 38.3]） |
| 5 | **失败注入** | 每个核心机制 ≥1 个「中途注入故障」臂 + 断言「失败可听」（Gaia2 的 noise/controlled failures 范式） |
| 6 | **人类基线** | 分数要么挂人类基线，要么明写「内部相对分，无外部意义」（ARC 的 RHAE = 对比人类第二好成绩） |
| 7 | **时间维度** | 显式记录「停滞天数」；Gaia2 里 `time` 分片是所有模型最难项 |

## 2. 外部标尺全景（2026-09 实检 · 只列出处可查的）

| 机制 | 出处 | 测什么 | 关键设计 / 数字 |
|:--|:--|:--|:--|
| **ARC-AGI-3** | arXiv:2603.24621 · arcprize.org/arc-agi/3 | 交互式：探索→建模→**自己推断目标**→规划。**无语言无指令** | 人类 **100%** 可解；frontier 模型 **<1%**（Gemini 3.1 Pro 0.37% / GPT-5.4 0.26% / Opus 4.6 0.25%）。指标 **RHAE**（相对人类动作效率，对比人类第二好，平方惩罚，逐关加权）。**官方榜禁 harness**：手搓 harness 在已见环境 97.1%、未见环境 **0.0%** ⇒ harness 分 ≠ 智商分 |
| **Gaia2 + ARE** | huggingface.co/blog/gaia2 · github meta-agents-research-environments | 真实助理：读+写、**歧义/噪声/受控失败**、时间敏感、动态事件 | 1000 场景；分片 `execution/search/time/ambiguity/adaptability`；**最难 = time**。**报 cost-performance Pareto（调用数 + 输出 token）** |
| **METR 度量学** | metr.org/notes/**2026-07-24-metrics-of-model-ability** · arXiv:2503.14499 | **方法学**：能力 = 分数-投入曲线 $s_A(x)$ vs 人类 $s_H(x)$ | 五种度量：固定投入取分 / 平台期 / **固定分数取最小投入** / **expenditure horizon** / **time horizon**。可靠性 = **`−log10(1−p)`「几个 9」**。警告（Kapoor et al. 2407.01502）：**最大化准确率 ⇒ 成本无界**（AlphaCode 1 次 0% → 1000 次 15% → 百万次 30%） |
| **τ²-bench** | github sierra-research/tau2-bench | 工具使用（agent + 模拟用户操同一数据库） | **pass^k** 测可靠性（非 pass@k）；查 DB 终态。⚠️ v1.0.1 改口径后**旧分不可比**（量具改口径 ⇒ 历史分作废的活例） |
| **GDPval** | arXiv:2510.04374 | 真实经济价值任务（44 职业/9 行业） | 专家盲评 win-rate + 速度 + 成本（**含复核与返工时间**） |
| **OSWorld 2.0** | osworld-v2.xlang.ai | 真实系统长程任务 | 维护者自述：*得分 83.5% 不代表问题解决，代表**基准停止测量问题了*** |
| **AMA-Bench** | arXiv:2602.22769 | **agent 记忆**（≠对话记忆）：Recall / Causal Inference / State Updating / State Abstraction | **架构 > 规模**（8B→32B 微增，换记忆系统大幅提升）；长上下文 >32K 后掉，图结构到 128K 仍稳 |
| **MemoryArena** | Stanford 2026-02 | 多会话**相互依赖**的 agentic 记忆 | 与「跨会话记忆」同构 |

**方法学共识**：三层评测栈 = **Outcome**（终态）/ **Step**（轨迹因果定位）/ **Meta**（评测本身的评测）。污染与饱和是常态（MMLU 88%+ 已饱和；静态基准随时间必然退化）。

## 3. 三条结构性结论（写进 rubric 时遵守）

1. **拆名**：工程成熟度（harness 质量：工具/prompt/上下文/错误恢复）**与**流体智能（探索/建模/目标设定/规划）**必须分表报**。
   混报一个数字会让所有读者误以为那是智商。
2. **评测必须先能预测事故**：真实事故（唤醒停摆 30 天 / 反馈环死 5 周）应能**反推**到某维扣分；
   做不到 ⇒ 维度切分与真实风险不同构。**每次事故后追问「哪一维本该预警」。**
3. **自评不是定评**：自评只作草稿；§1 第 4 条（异源裁判）是硬要求，**重大分歧（≥0.5）先查证据链，不要先改分数**。
