# Cheatsheet — 快速决策表

## 我在哪个阶段？
| 问自己 | 阶段 |
|--------|------|
| 我验证了真实问题吗（用户对话证据）？ | 没→Idea |
| 我有PMF证据（retention/付费/推荐）吗？ | 没→MVP |
| 增长可重复吗？公司系统化了吗？ | 没→Launch |
| 创始人不在了公司还转吗？ | 没→Scale |

## 反模式快速检查（任一命中=踩刹车）
- [ ] 我在建原型当验证？ → 回去做用户对话
- [ ] 我在加"就一个功能"？ → 读范围定义
- [ ] 我让AI为我的信念找证据？ → 反方向压力测试
- [ ] 用户数据上线但没安全审查？ → 停，先审查
- [ ] 决策等我1周？ → 审计+系统化
- [ ] 技术债在累积？ → 架构审计+重构

## 每个阶段Claude用什么
| 阶段 | Chat | Cowork | Code |
|------|------|--------|------|
| Idea | 头脑风暴/改写 | 深度研究/竞品/市场规模 | 不写码（先验证）|
| MVP | 快问答 | 架构上下文文档 | 写MVP+CLAUDE.md |
| Launch | 分诊修复排序 | 运营自动化 | 架构审计+重构+测试 |
| Scale | 瓶颈图 | 企业文档/SLA/工单路由 | 硬化+监控+可观测性 |

## 三大核心数字（记住）
- **42%**：创业失败因造了没人要的东西
- **三问**：Idea退出（问题真？方案对？信号够？）
- **三要素**：Launch退出（可重复增长/生产就绪/无瓶颈）
