# Glossary — 关键术语

| 术语 | 定义 | 章节 |
|------|------|------|
| **AI-native startup** | 以AI为核心基础设施（技术+组织）构建的创业公司 | ch01 |
| **Agentic coding** | 用自然语言描述→AI生成/测试/调试/重构生产代码的工具 | ch02 |
| **Agent orchestrator** | 新创始人角色——指挥AI代理系统而非亲自执行 | ch02 |
| **Problem-solution fit** | Idea阶段退出标准：真实问题被方案真实解决（三问全yes） | ch03 |
| **Product-market fit** | MVP阶段退出标准：用户 retention/revenue/referral 证据 | ch04 |
| **Premature scaling** | 反模式：执行远超验证——建造轻松时尤其危险 | ch03 |
| **AI technical debt** | 无specs/架构约束时，AI每会话重推导导致代码漂移复利 | ch04 |
| **CLAUDE.md** | 项目级持久上下文——AI原生项目的"记忆"文件 | ch04 |
| **Zero-friction scope creep** | 反模式：建造几乎免费→无限加功能→产品蔓延 | ch04 |
| **Founder bottleneck** | Launch阶段创始人还在每环→组织停滞 | ch05 |
| **GTM function** | Go-to-Market功能——Scale阶段有机增长见顶后必需 | ch06 |
| **Moat via accumulated depth** | 护城河=专业知识+集成深度+专有系统数据沉淀 | ch06 |
| **Bottleneck map** | 用"你消失一周会怎样"识别你还太亲力亲为的工作流 | ch06 |
