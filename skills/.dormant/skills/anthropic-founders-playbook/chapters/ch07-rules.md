# Chapter 7 — Same Job, New Rules

## 核心
创始人的工作没变——但2026年的规则全变了。

## 贯穿全书的规则
1. **Sense-making先于building**——尤其在建造毫不费力时
2. **上下文从第一天投入**——CLAUDE.md、specs、架构决策；否则每会话重推导，代码漂移
3. **三面配合**——Chat（快）、Cowork（文件/系统/自动化）、Code（代码库）共享模型，工作区不同
4. **验证不是建造**——原型是压力测试工具不是证据
5. **系统化前先全量审计**——你亲手处理的每件事：什么可系统化、可委托、什么值得创始人时间
6. **安全合规不可延期**——生产就绪前，不是建议是必修
7. **创始人的最高杠杆**：编排AI系统而非亲自执行——把时间给"只有创始人能做的决定"
