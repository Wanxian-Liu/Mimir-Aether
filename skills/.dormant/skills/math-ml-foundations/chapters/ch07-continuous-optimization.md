# 第 7 章：Continuous Optimization（连续优化）

## 核心框架

```
连续优化 = 凸性理论 + 一阶/二阶方法 + 约束优化/KKT
```

## 关键概念

| 概念 | 定义/判据 | 用途 |
|------|-----------|------|
| **凸集** | ∀x,y∈C, λ∈[0,1]: λx+(1-λ)y∈C | 可行域 |
| **凸函数** | f(λx+(1-λ)y) ≤ λf(x)+(1-λ)f(y) | 全局最优保证 |
| **强凸** | f(x) - (μ/2)‖x‖² 凸 (μ>0) | 线性收敛率 |
| **Lipschitz 梯度** | ‖∇f(x)-∇f(y)‖ ≤ L‖x-y‖ | 步长上界 1/L |
| **梯度下降** | x_{k+1} = x_k - η∇f(x_k) | 一阶通用 |
| **牛顿法** | x_{k+1} = x_k - H⁻¹∇f(x_k) | 二阶超线性收敛 |
| **KKT 条件** | 约束优化必要条件（正则性假设下） | SVM、投影、资源分配 |

## 核心算法对比

| 算法 | 收敛率 | 适用场景 | 缺点 |
|------|--------|----------|------|
| **GD** | O(1/k) (凸) / O(κ^k) (强凸) | 大规模、梯度易得 | 病态慢、需调 η |
| **Momentum** | O(1/k²) (Nesterov) | 凸光滑 | 超参敏感 |
| **Adam/RMSprop** | 经验自适应 | 深度学习、非凸 | 理论收敛弱 |
| **牛顿** | 二次 (局部) | 小中规模、二阶易得 | 计算/存海森贵 |
| **拟牛顿 (BFGS)** | 超线性 | 中规模、无显式海森 | 存 O(n²) |
| **L-BFGS** | 线性-超线性 | 大规模无约束 | 存 O(mn) |

## 约束优化

- **等式约束**：Lagrange 函数 L(x,ν) = f(x) + νᵀh(x) → ∇_x L=0, h(x)=0
- **不等式约束**：KKT 条件（站立性/原始可行/对偶可行/互补松弛）
- **投影梯度下降**：x_{k+1} = P_C(x_k - η∇f(x_k))

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 固定学习率不衰减 | 用 1/L、线搜索、或余弦退火 |
| 非凸问题只跑一次 GD | 多随机初始化 + 重启 |
| 忽略条件数 κ | 预处理/预条件子降低 κ |
| 约束优化只用惩罚法 | 惩罚参数难调；用投影/对偶/内点法 |

## 关键公式速查

- **凸判别（二阶）**：H_f(x) ≽ 0 ∀x ⇔ f 凸
- **强凸 ⇒ 唯一全局最小值**
- **GD 步长**：η ≤ 2/L（L 为梯度 Lipschitz 常数）
- **Nesterov 动量**：y_k = x_k + β_k(x_k - x_{k-1})
- **KKT**：∇f(x*) + Σ ν_i ∇h_i(x*) + Σ λ_j ∇g_j(x*) = 0；λ_j ≥ 0；λ_j g_j(x*) = 0
