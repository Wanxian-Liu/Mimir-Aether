# 第 9 章：Linear Regression（线性回归）

## 核心框架

```
线性回归 = 线性模型 + 高斯噪声假设 → 解析解 + 贝叶斯全后验
```

## 关键概念

| 概念 | 定义/公式 | 用途 |
|------|-----------|------|
| **线性模型** | f(x) = φ(x)ᵀθ（φ: 特征映射） | 基函数扩展、核化 |
| **似然** | p(y|X,θ) = N(y|Φθ, σ²I) | MLE 推导 |
| **MLE 解** | θ_MLE = (ΦᵀΦ)⁻¹Φᵀy = Φ⁺y | 普通最小二乘 |
| **MAP 解** | θ_MAP = (ΦᵀΦ + λI)⁻¹Φᵀy（λ=σ²/τ²） | Ridge 回归 = 高斯先验 |
| **贝叶斯线性回归** | 后验 p(θ|D) = N(θ|μ_N, Σ_N) | 预测分布、模型证据 |
| **预测分布** | p(y*|x*,D) = N(y*|φ*ᵀμ_N, σ²+φ*ᵀΣ_Nφ*) | 不确定性量化 |
| **模型证据** | p(D) = ∫ p(D|θ)p(θ)dθ | 模型选择/边缘似然 |

## 贝叶斯线性回归核心公式

- 后验精度：Σ_N⁻¹ = σ⁻²ΦᵀΦ + τ⁻²I
- 后验均值：μ_N = Σ_N σ⁻²Φᵀy
- 预测均值：φ*ᵀμ_N
- 预测方差：σ² + φ*ᵀΣ_Nφ*（aleatoric + epistemic）

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 直接求逆 (ΦᵀΦ)⁻¹ | 用 Cholesky/QR/SVD，数值稳定 |
| 忽略特征缩放 | 先标准化，再正则化，λ 才有可比性 |
| 只给点预测不给不确定性 | 贝叶斯/共形预测给区间 |
| 模型选择只看训练误差 | 用交叉验证/证据下界/WAIC |

## 关键公式速查

- **MLE**：θ̂ = (XᵀX)⁻¹Xᵀy
- **Ridge**：θ̂_λ = (XᵀX + λI)⁻¹Xᵀy
- **贝叶斯后验**：p(θ|D) = N(θ|Σ_N Xᵀy/σ², Σ_N)，Σ_N = (XᵀX/σ² + I/τ²)⁻¹
- **预测分布**：y*|x*,D ~ N(x*ᵀμ_N, σ² + x*ᵀΣ_N x*)
