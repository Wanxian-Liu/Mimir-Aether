# 第 4 章：Matrix Decompositions（矩阵分解）

## 核心框架

```
矩阵分解 = 结构揭示工具
  行列式/迹 → 不变量
  特征分解 → 方阵/对称矩阵谱结构
  SVD      → 任意矩阵通用分解（核心）
  QR/Cholesky → 数值求解专用
```

## 关键分解

| 分解 | 形式 | 条件 | 核心用途 |
|------|------|------|----------|
| **行列式** | det(A) = Π λ_i | 方阵 | 可逆性、体积缩放 |
| **迹** | tr(A) = Σ λ_i | 方阵 | 梯度简化、期望计算 |
| **特征分解** | A = QΛQᵀ | 实对称 | PCA、谱聚类、二次型 |
| **SVD** | A = UΣVᵀ | 任意 m×n | **万能**——PCA/推荐/压缩/伪逆/正则化 |
| **QR** | A = QR (Q正交, R上三角) | 满列秩 | 最小二乘、Gram-Schmidt 数值稳定版 |
| **Cholesky** | A = LLᵀ | 对称正定 | 高斯采样、优化、KALMAN |

## SVD 核心性质

- A = UΣVᵀ，U∈R^{m×m} 正交，V∈R^{n×n} 正交，Σ∈R^{m×n} 对角非负
- 奇异值 σ₁ ≥ σ₂ ≥ ... ≥ σ_r > 0，r = rank(A)
- 列空间 = U 前 r 列；零空间 = V 后 n-r 列
- **Eckart-Young 定理**：A_k = Σ_{i=1}^k σ_i u_i v_iᵀ 是秩 k 下最优 Frobenius/谱范数近似
- 伪逆：A⁺ = VΣ⁺Uᵀ，Σ⁺ 对角线倒数（非零奇异值）

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 特征分解用于非对称/非方阵 | 必须用 SVD |
| 直接算 (AᵀA)⁻¹ 做最小二乘 | 用 QR 或 SVD，避免条件数平方 |
| 忽略奇异值衰减 | σ_i 快速衰减 → 低秩结构 → 截断 SVD 压缩/去噪 |
| 认为 Cholesky 通用 | 仅限对称正定；半正定用 LDLᵀ 或带旋转的 Cholesky |

## 关键公式速查

- **行列式性质**：det(AB) = det(A)det(B)；det(Aᵀ) = det(A)；det(A⁻¹) = 1/det(A)
- **迹性质**：tr(ABC) = tr(CAB) = tr(BCA)；∇_X tr(XᵀA) = A
- **特征分解**：实对称 A = QΛQᵀ，Λ=diag(λ)，Q正交
- **SVD 计算伪逆**：A⁺ = V diag(1/σ₁,...,1/σ_r,0,...) Uᵀ
- **Cholesky**：A = LLᵀ，L 下三角；解 Ax=b 先解 Ly=b 再 Lᵀx=y
