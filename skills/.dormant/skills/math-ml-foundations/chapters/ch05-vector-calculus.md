# 第 5 章：Vector Calculus（向量微积分）

## 核心框架

```
向量微积分 = 标量/向量/矩阵函数的导数 + 链式法则 + 自动微分原理
```

## 关键概念

| 概念 | 定义/维度 | 用途 |
|------|-----------|------|
| **梯度** | ∇f(x) ∈ R^n（f: R^n→R） | 一阶优化方向、反向传播 |
| **雅可比矩阵** | J_f(x) ∈ R^{m×n}（f: R^n→R^m） | 向量函数一阶导数、链式法则核心 |
| **海森矩阵** | H_f(x) ∈ R^{n×n}（f: R^n→R） | 二阶优化、凸性判断、牛顿法 |
| **矩阵导数** | ∂f/∂X ∈ R^{m×n} | 模型参数梯度、变分推断 |

## 核心法则

1. **链式法则（标量）**：df/dx = Σ_i (∂f/∂y_i)(dy_i/dx)
2. **链式法则（向量/矩阵）**：J_{f∘g}(x) = J_f(g(x)) J_g(x)
3. **向量-矩阵导数布局**：
   - 分子布局：∂(Ax)/∂x = Aᵀ（列向量对列向量）
   - 分母布局：∂(Ax)/∂x = A（行向量对列向量） —— **本书用分母布局**
4. **常用恒等式**：
   - ∂(xᵀAx)/∂x = (A + Aᵀ)x
   - ∂(aᵀXb)/∂X = abᵀ
   - ∂log det(X)/∂X = X⁻ᵀ
   - ∂tr(AXB)/∂X = AᵀBᵀ

## 反向传播/自动微分原理

- **前向模式**：计算 J_f(x)v（种子向量 v）→ 适合 n ≪ m
- **反向模式**：计算 vᵀJ_f(x)（伴随向量 v）→ 适合 n ≫ m（**DL 标配**）
- **计算图**：节点=变量/算子，边=数据流；反向累积梯度

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 手写复杂梯度不验证 | 用有限差分检查：∂f/∂x_i ≈ (f(x+εe_i)-f(x-εe_i))/(2ε) |
| 忽略广播语义导致形状错 | 显式写出维度，用 `einsum`/显式 reshape |
| 认为海森矩阵总正定 | 仅凸函数处处正定；鞍点处海森不定 |
| 反向传播不理解链式法则 | 画计算图，每个节点存局部导数，反向累积 |

## 关键公式速查

- ∇(xᵀAx) = (A + Aᵀ)x
- ∇(aᵀXb) = abᵀ
- ∇_X log det(X) = X⁻ᵀ
- ∇_X tr(XᵀAXB) = AXBᵀ + AᵀXB
- ∇_X ‖AX - B‖²_F = 2Aᵀ(AX - B)
- 反向传播核心：δ^{(l)} = (W^{(l+1)})ᵀ δ^{(l+1)} ⊙ σ'(z^{(l)})
