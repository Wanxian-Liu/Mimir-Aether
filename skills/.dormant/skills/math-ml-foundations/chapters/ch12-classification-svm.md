# 第 12 章：Classification with SVM（支持向量机分类）

## 核心框架

```
SVM = 最大间隔分类器 + 核技巧 + 对偶优化
```

## 关键概念

| 概念 | 定义/公式 | 用途 |
|------|-----------|------|
| **硬间隔** | min ½‖w‖² s.t. y_i(wᵀx_i + b) ≥ 1 | 线性可分理想情况 |
| **软间隔** | min ½‖w‖² + C Σ ξ_i s.t. y_i(wᵀx_i + b) ≥ 1-ξ_i, ξ_i≥0 | 现实噪声数据 |
| **对偶形式** | max Σ α_i - ½ Σ Σ α_i α_j y_i y_j x_iᵀx_j s.t. 0≤α_i≤C, Σ α_i y_i=0 | 核化入口 |
| **核函数** | K(x,x') = ⟨φ(x), φ(x')⟩ | 隐式高维映射 |
| **支持向量** | α_i > 0 的样本 | 决策边界仅由 SV 决定 |
| **KKT 条件** | α_i[y_i(wᵀx_i+b)-1+ξ_i]=0, ξ_i(C-α_i)=0 | 求解/检查最优性 |

## 常用核

| 核 | 公式 | 适用场景 |
|----|------|----------|
| **线性核** | K(x,x') = xᵀx' | 高维稀疏、文本、基因 |
| **RBF/高斯核** | exp(-γ‖x-x'‖²) | 通用非线性、默认首选 |
| **多项式核** | (γ xᵀx' + r)^d | 多项式决策边界 |
| **Sigmoid核** | tanh(γ xᵀx' + r) | 类神经网络 |

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 只调 C 不选核 | 核决定假设空间，先网格搜核类型+参数 |
| 不标准化直接用 RBF | 必须标准化，否则大量纲特征主导距离 |
| 认为 SVM 概率输出可靠 | Platt scaling (Sigmoid 拟合) 校准 |
| 忽略类别不平衡 | 类别加权 C_+ / C_- 或采样 |

## 关键公式速查

- **原始问题**：min ½‖w‖² + C Σ ξ_i
- **对偶**：max_α Σ α_i - ½ Σ_i Σ_j α_i α_j y_i y_j K(x_i,x_j)
- **决策函数**：f(x) = sign(Σ_i α_i y_i K(x_i,x) + b)
- **偏置 b**：任取 0<α_i<C 的 SV 算 b = y_i - Σ_j α_j y_j K(x_j,x_i)
- **核矩阵**：K_ij = K(x_i,x_j)（半正定）
