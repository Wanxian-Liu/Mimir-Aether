# 第 6 章：Probability and Distributions（概率与分布）

## 核心框架

```
概率论 = 概率空间 + 随机变量 + 贝叶斯推断 + 指数族 + 共轭先验
```

## 关键概念

| 概念 | 定义/性质 | 用途 |
|------|-----------|------|
| **概率空间** | (Ω, F, P)：样本空间/σ-代数/概率测度 | 严格基础 |
| **随机变量** | X: Ω→R 可测函数 | 建模不确定性 |
| **期望/方差** | E[X] = ∫ x p(x)dx；Var[X] = E[(X-E[X])²] | 损失函数、风险 |
| **贝叶斯定理** | p(θ|D) = p(D|θ)p(θ)/p(D) | 后验推断、模型选择 |
| **指数族** | p(x|η) = h(x)exp(ηᵀT(x) - A(η)) | 统一框架、共轭先验存在 |
| **高斯分布** | N(μ, Σ)；边缘/条件仍是高斯 | 线性高斯系统、KF、GP |
| **共轭先验** | 先验∈指数族 ⇒ 后验同族 | 解析后验、在线更新 |

## 核心分布表

| 分布 | 参数 | 用途 | 共轭先验 |
|------|------|------|----------|
| **Bernoulli** | θ ∈ [0,1] | 二分类 | Beta |
| **Binomial** | n, θ | 计数 | Beta |
| **Categorical** | θ ∈ Δ^{K-1} | 多分类 | Dirichlet |
| **Multinomial** | n, θ | 多次计数 | Dirichlet |
| **Poisson** | λ > 0 | 稀疏计数 | Gamma |
| **Exponential** | λ > 0 | 等待时间 | Gamma |
| **Gamma** | α, β > 0 | 正值、精度先验 | Gamma |
| **Beta** | α, β > 0 | 概率先验 | Beta |
| **Dirichlet** | α ∈ R^K_+ | 分布先验 | Dirichlet |
| **高斯** | μ, Σ | 连续回归、潜变量 | Normal-Inverse-Wishart |

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 混淆概率密度与概率 | 连续变量 p(x) 不是概率，概率是 ∫p(x)dx |
| 忽略归一化常数 Z | 做比较/采样时常可忽略，但计算模型证据必须保留 |
| 高维高斯直接存 Σ | 用精度矩阵 Λ=Σ⁻¹ 或 Cholesky 因子存储 |
| 认为贝叶斯一定比频率派好 | 小样本/有先验知识时贝叶斯强；大样本频率派更简 |

## 关键公式速查

- **贝叶斯**：p(θ|D) ∝ p(D|θ)p(θ)
- **高斯边缘化**：x = [x_a; x_b] ~ N(μ, Σ) ⇒ x_a ~ N(μ_a, Σ_aa)
- **高斯条件**：x_b|x_a ~ N(μ_b + Σ_ba Σ_aa⁻¹(x_a - μ_a), Σ_bb - Σ_ba Σ_aa⁻¹ Σ_ab)
- **指数族充分统计量**：T(x)；自然参数 η；对数配分函数 A(η)
- **高斯 KL 散度**：KL(N₀||N₁) = ½[tr(Σ₁⁻¹Σ₀) + (μ₁-μ₀)ᵀΣ₁⁻¹(μ₁-μ₀) - k + ln(det Σ₁/det Σ₀)]
