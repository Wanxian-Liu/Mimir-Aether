# 第 2 章：Linear Algebra（线性代数）

## 核心框架

```
线性代数 = 向量空间 + 线性映射 + 矩阵表示 + 特征分解/SVD
```

## 关键概念

| 概念 | 定义/性质 | 用途 |
|------|-----------|------|
| **向量空间** | 满足封闭性（加法+数乘）的集合，含零向量、加法逆元 | 所有 ML 数据的底层代数结构 |
| **子空间** | 向量空间的非空子集，自身也是向量空间 | 解空间、列空间、零空间 |
| **基** | 线性无关且张成空间的一组向量；维数 = 基向量个数 | 坐标表示、降维 |
| **线性映射** | 保持加法和数乘的映射 f: V→W；对应矩阵乘法 | 模型层、变换、投影 |
| **矩阵表示** | 线性映射在选定基下的矩阵；换基 = 相似变换 | 算法实现、数值计算 |
| **秩** | 列空间维数 = 行空间维数 = 非零奇异值个数 | 信息量、可逆性、压缩 |
| **特征值/特征向量** | Av = λv；实对称矩阵可正交对角化 | PCA、谱聚类、稳定性分析 |
| **奇异值分解 (SVD)** | A = UΣVᵀ；U,V 正交，Σ 对角非负 | **全书核心工具**——PCA/推荐/压缩/求解 |

## 核心定理/结论

1. **秩-零空间定理**：rank(A) + nullity(A) = n（列数）
2. **谱定理**：实对称矩阵 A = QΛQᵀ，Q 正交，Λ 实对角
3. **SVD 存在性**：任意实矩阵 A = UΣVᵀ（U∈R^{m×m}, V∈R^{n×n} 正交）
4. **最小二乘正规方程**：AᵀAx = Aᵀb（当 A 满列秩时唯一解 x = (AᵀA)⁻¹Aᵀb）
5. **伪逆**：A⁺ = VΣ⁺Uᵀ；最小范数最小二乘解 x = A⁺b

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 直接求逆 (A⁻¹) 解线性方程 | 用 LU/Cholesky/QR 分解 + 前向/后向代入 |
| 忽略条件数 κ(A) | κ(A) = σ_max/σ_min；大 κ → 数值不稳，用 SVD 截断 |
| 当向量是 "数组" 而非空间元素 | 理解三视角：数组/几何箭头/代数对象（加法+数乘） |
| 特征分解用于非对称/非方阵 | 非方阵/非对称必须用 SVD |

## 关键公式速查

- **线性映射矩阵**：f(v) = Av，A 的第 j 列 = f(e_j) 在目标基下的坐标
- **换基**：A' = P⁻¹AP（P 为新基向量在旧基下的坐标矩阵）
- **正交投影矩阵**：P_U = A(AᵀA)⁻¹Aᵀ（列向量张成子空间 U）
- **SVD 低秩近似**：A_k = Σ_{i=1}^k σ_i u_i v_iᵀ（Eckart-Young 定理：最优秩 k 近似）
