# 第 3 章：Analytic Geometry（解析几何）

## 核心框架

```
解析几何 = 内积空间 + 范数/距离/角度 + 正交投影 + Gram-Schmidt 正交化
```

## 关键概念

| 概念 | 定义/公式 | 用途 |
|------|-----------|------|
| **内积** | ⟨x, y⟩ = xᵀAy（A 对称正定）| 广义相似度、核方法基础 |
| **范数** | ‖x‖ = √⟨x, x⟩ | 向量长度、正则化项 |
| **距离** | d(x, y) = ‖x - y‖ | KNN、聚类、SVM 间隔 |
| **角度** | cos θ = ⟨x, y⟩ / (‖x‖‖y‖) | 余弦相似度、正交性判定 |
| **正交投影** | π_U(x) = A(AᵀA)⁻¹Aᵀx | PCA、最小二乘、降噪 |
| **Gram-Schmidt** | 从任意基构造标准正交基 | 数值稳定的 QR 分解前身 |
| **正交补** | U^⊥ = {v : ⟨v, u⟩ = 0, ∀u∈U} | 子空间分解、残差空间 |

## 核心定理

1. **柯西-施瓦茨不等式**：|⟨x, y⟩| ≤ ‖x‖‖y‖（等号当且仅当 x, y 线性相关）
2. **三角不等式**：‖x + y‖ ≤ ‖x‖ + ‖y‖
3. **投影定理**：对任意子空间 U，x = π_U(x) + π_{U^⊥}(x)（唯一分解）
4. **最佳近似性质**：π_U(x) 是 U 中到 x 最近的点

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 用欧氏距离做高维相似度 | 高维下距离失去辨别力，改用余弦/核距离 |
| 忽略数值稳定性直接算投影 | 用 QR 分解（A=QR）→ π_U(x) = QQᵀx，避免 (AᵀA)⁻¹ 病态 |
| 认为正交 = 线性无关 | 正交⇒线性无关，逆不成立（需正交化） |

## 关键公式速查

- **标准内积**：⟨x, y⟩ = xᵀy = Σ x_i y_i
- **加权内积**：⟨x, y⟩_A = xᵀAy（A ≻ 0）
- **投影矩阵**：P = QQᵀ（Q 列标准正交张成 U）
- **Gram-Schmidt**：u_1 = v_1；u_k = v_k - Σ_{j<k} ⟨v_k, u_j⟩/⟨u_j, u_j⟩ u_j
- **函数内积**：⟨f, g⟩ = ∫ f(x)g(x)w(x)dx（核方法/RKHS 基础）
