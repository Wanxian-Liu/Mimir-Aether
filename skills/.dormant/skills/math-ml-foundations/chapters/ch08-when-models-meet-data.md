# 第 8 章：When Models Meet Data（模型遇见数据）

## 核心框架

```
三要素数学化：
  数据   → 训练集/验证集/测试集（i.i.d. 假设）
  模型   → 参数化族 {f_θ} + 损失函数 L(θ)
  学习   → 经验风险最小化 + 泛化间隙控制
```

## 关键概念

| 概念 | 定义/方法 | 用途 |
|------|-----------|------|
| **经验风险** | R_emp(θ) = (1/n) Σ L(f_θ(x_i), y_i) | 训练目标 |
| **期望风险** | R(θ) = E_{(x,y)~P}[L(f_θ(x), y)] | 真实目标 |
| **泛化间隙** | R(θ) - R_emp(θ) | 过拟合度量 |
| **交叉验证** | K-fold CV 估计泛化误差 | 模型选择、超参调优 |
| **正则化** | R_emp(θ) + λΩ(θ) | 控制复杂度、防过拟合 |
| **偏差-方差分解** | E[(f̂-y)²] = Bias² + Var + Noise | 理解模型行为 |

## 核心原则

1. **训练/测试严格分离** —— 测试集只用一次，验证集可多次
2. **i.i.d. 假设是根基** —— 分布漂移会失效
3. **模型复杂度需显式控制** —— 显式正则化 / 早停 / 贝叶斯边缘似然
4. **无免费午餐** —— 没有通用最优算法，需匹配问题结构

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 测试集反复调参 | 测试集锁死，最后只评估一次 |
| 只看训练 loss 下降 | 必须监控验证 loss，早停 |
| 认为更复杂模型总更好 | 奥卡姆剃刀：同性能选简单模型 |
| 忽略数据泄露 | 特征工程/归一化必须只在训练集拟合 |

## 关键公式速查

- **泛化界（VC 维）**：R(θ) ≤ R_emp(θ) + O(√(VC log n / n))
- **Ridge 回归**：min ‖Xθ - y‖² + λ‖θ‖² → θ = (XᵀX + λI)⁻¹Xᵀy
- **LASSO**：min ‖Xθ - y‖² + λ‖θ‖₁（稀疏解）
- **早停等价**：早停 ≈ L2 正则化
