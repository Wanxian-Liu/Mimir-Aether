# 第 10 章：Dimensionality Reduction with PCA（主成分分析）

## 核心框架

```
PCA = 最大方差投影 = 最小重构误差 = SVD 截断
```

## 关键概念

| 概念 | 定义/公式 | 用途 |
|------|-----------|------|
| **协方差矩阵** | Σ = (1/n) XᵀX（X 已中心化） | 数据散布结构 |
| **主成分** | Σ 的特征向量，按特征值降序 | 新坐标轴 |
| **投影** | Z = XW（W = 前 k 个特征向量） | 降维、可视化 |
| **重构** | X̃ = ZWᵀ | 压缩、去噪 |
| **解释方差比** | λ_k / Σ λ_i | 选主成分数 |

## 核心定理

1. **PCA 最优性**：秩 k 线性投影中，PCA 最小化重构误差 ‖X - X̃‖²_F
2. **SVD 等价**：X = UΣVᵀ ⇒ 主成分 = V，投影 = U_kΣ_k
3. **最大方差**：第 1 主成分最大化投影方差

## 算法步骤

1. 中心化：X ← X - mean(X)
2. SVD：X = UΣVᵀ（或特征分解 Σ = VΛVᵀ）
3. 取前 k 列 V_k
4. 投影：Z = XV_k

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 不中心化直接做 SVD | 必须中心化，否则第 1 成分指向均值 |
| 用特征分解不做 SVD | SVD 数值更稳，且直接给投影坐标 UΣ |
| 固定 k 不看解释方差 | 看累积解释方差比（如 95%）决定 k |
| 忽略缩放 | 特征量纲不同须先标准化（相关性矩阵 PCA） |

## 关键公式速查

- **协方差**：Σ = (1/(n-1)) XᵀX
- **特征分解**：Σ = VΛVᵀ
- **投影**：Z = XV_k
- **重构**：X̃ = ZV_kᵀ
- **重构误差**：‖X - X̃‖²_F = Σ_{i=k+1}^r σ_i²
- **解释方差比**：λ_k / Σ λ_i
