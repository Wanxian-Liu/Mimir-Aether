# 第 11 章：Density Estimation with GMM（高斯混合模型密度估计）

## 核心框架

```
密度估计 = 参数化密度建模 → EM 算法 → 模型选择
```

## 关键概念

| 概念 | 定义/公式 | 用途 |
|------|-----------|------|
| **混合高斯** | p(x) = Σ_{k=1}^K π_k N(x|μ_k, Σ_k) | 多模态密度、聚类 |
| **隐变量** | z ∈ {1..K}^n，指示每点来自哪成分 | EM 推断 |
| **EM 算法** | E步：计算责任 γ_ik = p(z_i=k|x_i)；M步：更新 π/μ/Σ | 最大化不完全数据似然 |
| **模型选择** | BIC/AIC/交叉验证/Dirichlet 过程 | 选 K |

## EM 算法步骤

**E 步**：γ_ik = π_k N(x_i|μ_k, Σ_k) / Σ_j π_j N(x_i|μ_j, Σ_j)

**M 步**：
- π_k = (1/n) Σ_i γ_ik
- μ_k = Σ_i γ_ik x_i / Σ_i γ_ik
- Σ_k = Σ_i γ_ik (x_i - μ_k)(x_i - μ_k)ᵀ / Σ_i γ_ik

## 反模式/坑

| 反模式 | 正确做法 |
|--------|----------|
| 单次随机初始化 | 多次随机初始化 + k-means 初始化，取最优 |
| 忽略奇异解（Σ_k→0） | 加正则化/先验、或限制最小特征值 |
| 认为 EM 收敛 = 全局最优 | 仅保证局部最优，多重启动 |
| 固定 K 不选模型 | BIC = -2 log L + K log n（含参数数） |

## 关键公式速查

- **GMM 似然**：log p(X|θ) = Σ_i log Σ_k π_k N(x_i|μ_k, Σ_k)
- **BIC**：-2 log L_max + d log n（d = K-1 + K·D + K·D(D+1)/2）
- **责任归一化**：Σ_k γ_ik = 1
- **变分推断**：引入 q(z) 近似 p(z|X)，优化 ELBO = E_q[log p(X,z)] - E_q[log q(z)]
