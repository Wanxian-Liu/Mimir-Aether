## 一、发现的 2 个 Bug

### Bug 1: `if ci > 0` 跳过负步 (P0)

**位置**: `_leapfrog4_step()` 原 L176

```python
# 原代码
for ci in coeffs:
    if ci > 0:                          # ← BUG: 跳过负步
        s = self._verlet_step(s, t_cur, ci * dt)
    t_cur += ci * dt
```

**影响**: Yoshida 四阶构造要求 4 个子步全部执行 (含 d2=d3=-0.176 的负步)。跳过负步 → 四阶退化到二阶，物理时间偏移 35%。

**修复**: 去掉 `if ci > 0`，Verlet 时间可逆已验证支持负步长 (正反向误差 = 机器精度 6.77e-17)。

---

### Bug 2: 4步子步分解 → 应改用 3步完整 Verlet (P0)

**位置**: `_leapfrog4_step()` 原分解方式

**根因**: Yoshida 1990 的公式是:

```
S_4(dt) = S_2(w1*dt) ∘ S_2(w0*dt) ∘ S_2(w1*dt)
```

其中 S_2 是**完整** Velocity Verlet 步。原代码将每个 S_2 拆成两个半步 (d1..d4 = 4 个子步)，但两个完整 Verlet 步不等价于一个完整 Verlet 步 (只在线性问题成立)。对非线性弹簧振子 → 四阶退化到二阶 (收敛阶 2.02)。

**修复**: 直接用 3 个完整 Verlet 步，系数 [w1, w0, w1]：

```python
coeffs = [w1, w0, w1]  # 3 个完整 Verlet 步
```
