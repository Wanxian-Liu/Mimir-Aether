# Architecture Diagram

Generate dark-themed SVG architecture/cloud/infra diagrams as standalone HTML files.

## When to use

- Architecture diagrams, cloud infrastructure diagrams, system design visualizations
- Network topology, data flow diagrams, deployment architecture
- When you need a clean dark-themed SVG that can be opened in browser or embedded

## How it works

Generate a standalone HTML file containing inline SVG with dark theme styling. The output is a single self-contained HTML file.

## Key features

- Dark theme by default
- Clean SVG rendering
- No external dependencies
- Browser-ready HTML output
- Suitable for cloud architecture (AWS, GCP, Azure), system design, network topology

## Usage

Ask the agent: "Create an architecture diagram for [your system]" and specify what components and connections to show.

## Notes

- Output is always a `.html` file with embedded SVG
- Designed for dark backgrounds
- Keep diagrams focused — don't try to show everything in one diagram
