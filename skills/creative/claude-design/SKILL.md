# Claude Design — HTML Artifacts

Design and generate one-off HTML artifacts: landing pages, slide decks, interactive prototypes, and UI mockups.

## When to use

- Landing pages and marketing pages
- Presentation decks (HTML-based slides)
- Interactive prototypes and UI mockups
- Design system exploration
- Motion design and micro-interactions
- When a user wants a "design" or "prototype" or "landing page"

## Key features

- Single HTML file output (self-contained)
- Dark/light theme support
- Responsive design
- CSS animations and transitions
- No external dependencies needed
- Browser-ready

## Usage

Ask the agent: "Design a [landing page / deck / prototype] for [purpose]" with specifics about content and style preferences.

## Notes

- Output is a single `.html` file — everything inline
- Focus on visual design and UX
- Works best for one-off artifacts, not production sites
- Combine with excalidraw for architecture/flow diagrams
