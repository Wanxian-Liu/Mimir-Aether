# Baoyu Comic — 知识漫画

Generate educational knowledge comics: multi-panel comic strips that explain concepts, tell stories, or present tutorials in an engaging visual format.

## When to use

- Explaining complex concepts through visual storytelling
- Creating educational content that's more engaging than plain text
- Biography summaries, historical events, tutorial walkthroughs
- When a user asks for a "comic" or "知识漫画"

## Key features

- Multi-panel comic layout
- Character-driven storytelling
- Educational/instructional focus
- Chinese language support (知识漫画)
- Image generation based output

## Usage

Ask the agent: "Create a knowledge comic about [topic]" specifying the concept or story to visualize.

## Notes

- Best for concepts that benefit from sequential visual explanation
- Combine with image generation tools for panel artwork
- Keep text concise per panel — show, don't tell
