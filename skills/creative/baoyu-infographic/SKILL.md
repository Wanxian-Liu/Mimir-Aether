# Baoyu Infographic — 信息图

Generate infographics with 21 layout patterns × 21 visual styles for data visualization and information presentation.

## When to use

- Presenting data, statistics, or comparisons visually
- Creating visual summaries of reports or articles
- Timeline visualizations, process flows, hierarchical data
- When a user asks for an "infographic" or "信息图"
- When plain text isn't enough to convey relationships

## Key features

- 21 layout patterns (timeline, comparison, hierarchy, flow, grid, etc.)
- 21 visual styles (minimal, bold, tech, nature, retro, etc.)
- 441 possible combinations
- Data-driven layout
- Image generation based output

## Usage

Ask the agent: "Create an infographic about [topic/data]" specifying what information to visualize.

## Notes

- Choose layout based on data structure (timeline → chronological, comparison → side-by-side, hierarchy → tree)
- Choose style based on audience and context
- Less is more — don't overcrowd the infographic
