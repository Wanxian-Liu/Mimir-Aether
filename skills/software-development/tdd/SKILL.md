# TDD Skill - 测试驱动开发

测试驱动开发工作流，集成TDD最佳实践，引导完成红-绿-重构循环。

## TDD循环

1. **红 (Red)** - 先写失败的测试
2. **绿 (Green)** - 写最简代码让测试通过
3. **重构 (Refactor)** - 优化代码，保持测试通过

## 使用流程

1. 理解需求，定义预期行为
2. 编写测试（预期失败）
3. 实现最小代码
4. 重构优化
5. 验证测试通过

## 原则

- 测试先行
- 快速反馈
- 保持简洁
- 持续重构
