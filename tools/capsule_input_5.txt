天工流程V1.2.0核心知识：

1. 三个核心流程
   - 新技能生产：衍化 → 创造 → 封装 → 落地
   - 技能迭代：析构 → 衍化 → 创造 → 封装 → 落地
   - 技能拆解：析构

2. 天工基座（已安装）
   - 观察器 V1.01：感知环境变化
   - 析构 V1.01：分解技能结构
   - 熔炉 V1.01：重组创新

3. 衍化阶段
   - 观察现有技能和问题
   - 寻找可借鉴的模式
   - 制定进化方向

4. 创造阶段
   - 设计新技能架构
   - 编写核心代码
   - 保持与现有系统兼容

5. 封装阶段
   - 标准化接口
   - 编写SKILL.md
   - 配置元数据

6. 落地阶段
   - 安装到正确位置
   - 测试验证
   - 更新MEMORY.md记录

7. 定向完善原则（2026-03-21 刘哥确认）
   - 定向进化：完善A就只做A的进化
   - 冗余删除：完善后发现某组件无用，直接删除
   - 范围控制：一次只改一个组件
